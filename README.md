# TechStore PHP

Tienda de informática en PHP puro: catálogo, búsqueda, carrito en sesión, compra con descuento e IVA, y preferencias en cookies. Sin base de datos.

## Requisitos

- PHP 8.1 o superior

## Arrancar

php -S localhost:8000

Abrir http://localhost:8000

## Estado

Sprint 0: estructura inicial.
